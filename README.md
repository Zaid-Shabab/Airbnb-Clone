# Airbnb Clone 🏡

Hey! This is my **Airbnb Clone** project.

I made this project while learning and practicing **backend and full-stack web development**. The main idea was to build a website where users can create accounts, add listings, view other listings and leave reviews.

It's inspired by Airbnb, but this is just a practice project and not the real Airbnb website.

## 🌐 Live Website

You can check out the project here:

https://airbnb-clone-wv0y.onrender.com/

## 🚀 Run It Locally

Clone the repository:

```bash id="k3m7qz"
git clone https://github.com/Zaid-Shabab/Airbnb-Clone.git
cd Airbnb-Clone
```

Install the packages:

```bash id="h6n2rx"
npm install
```

Create a `.env` file in the project folder:

```env id="v8p1kd"
ATLASDB_URL=your_mongodb_connection_string
SECRET=your_secret_key
```

Then run:

```bash id="s9x4jw"
node app.js
```

Now open:

```text id="m2c7qa"
http://localhost:8080
```

## 🔐 Environment Variables

The project uses two environment variables:

* `ATLASDB_URL` for the MongoDB connection
* `SECRET` for session security

Don't share or upload your `.env` file because it contains private information.
